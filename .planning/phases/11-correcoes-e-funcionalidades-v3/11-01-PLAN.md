## Objetivo

Permitir que qualquer usuário autenticado faça upload de uma foto de perfil (JPG/PNG, max 2MB) e que essa foto seja exibida em todo o sistema (sidebar, perfil, admin users).

## must_haves

- Endpoint `POST /api/auth/avatar` que recebe multipart/form-data com campo `avatar`
- Foto salva em `backend/public/uploads/avatars/` com nome único
- Campo `avatarUrl` atualizado no banco para o usuário autenticado
- Frontend exibe preview da foto antes do upload
- Após upload, a foto aparece no componente de perfil e na sidebar (substituindo a inicial)
- Endpoint `GET /me` retorna `avatarUrl` no payload

<task id="11-01-T1">
<title>Criar endpoint de upload de avatar no backend</title>

<read_first>
- backend/src/routes/inventory.routes.ts (referência de como multer está configurado)
- backend/src/routes/auth.routes.ts (rotas de auth existentes)
- backend/src/controllers/auth.controller.ts (controller de auth existente)
- backend/prisma/schema.prisma (campo avatarUrl já existe no modelo User)
</read_first>

<action>
1. Em `backend/src/routes/auth.routes.ts`:
   - Importar `multer` e `path`
   - Configurar storage para `backend/public/uploads/avatars/`:
     ```ts
     const avatarStorage = multer.diskStorage({
       destination: (_req, _file, cb) => cb(null, path.join(__dirname, '../../public/uploads/avatars')),
       filename: (_req, file, cb) => {
         const ext = path.extname(file.originalname);
         const uniqueSuffix = Date.now() + '-' + Math.round(Math.random() * 1e9);
         cb(null, `avatar-${uniqueSuffix}${ext}`);
       },
     });
     ```
   - Criar instância `const uploadAvatar = multer({ storage: avatarStorage, limits: { fileSize: 2 * 1024 * 1024 }, fileFilter: ... })` permitindo apenas image/jpeg e image/png
   - Adicionar rota: `router.post('/avatar', requireAuth, uploadAvatar.single('avatar'), uploadAvatarHandler);`

2. Em `backend/src/controllers/auth.controller.ts`:
   - Criar função `uploadAvatarHandler(req, res, next)`:
     - Verificar `req.file` existe, senão `AppError('Nenhum arquivo enviado', 400)`
     - Construir `avatarUrl = 'uploads/avatars/' + req.file.filename`
     - `prisma.user.update({ where: { id: req.user.id }, data: { avatarUrl } })`
     - Retornar `sendSuccess(res, { avatarUrl }, 'Foto de perfil atualizada')`

3. Criar diretório `backend/public/uploads/avatars/` com `.gitkeep`

4. Garantir que `backend/src/app.ts` serve arquivos estáticos de `public/`:
   - Verificar se `app.use('/uploads', express.static(path.join(__dirname, '../public/uploads')))` existe, senão adicionar
</action>

<acceptance_criteria>

- Enviar POST `/api/auth/avatar` com multipart retorna `{ success: true, data: { avatarUrl: 'uploads/avatars/...' } }`

</task>
