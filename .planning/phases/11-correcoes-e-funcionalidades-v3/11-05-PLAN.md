## Objetivo

Corrigir problemas de alinhamento entre o mecanismo de notificações e o fluxo de aprovação de empréstimos:

### Problemas identificados na análise do código:

1. **Aprovação envia `dueDate` e `observation` mas o backend `updateLoanStatusSchema` não valida esses campos** — O frontend envia `{ status: "active", dueDate: "...", observation: "..." }` mas o schema só aceita `{ status, labObservation }`. O campo `observation` não é mapeado para `labObservation` e `dueDate` não é processado no update.

2. **Notificação de delete é só local** — O frontend faz `setNotifications(prev => prev.filter(...))` mas não tem endpoint DELETE no backend para remover a notificação do banco.

3. **markAsRead envia PUT sem body** — O frontend chama `api.put('/notifications/${id}/read')` sem body, mas o backend espera `{ read: true }` no body (validado pelo `updateNotificationSchema`).

4. **Sem notificação para empréstimos atrasados** — O backend não cria notificações de tipo `overdue` quando um empréstimo ultrapassa a `dueDate`.

5. **Sem badge de contagem no sidebar** — A sidebar não mostra quantas notificações não lidas o usuário tem.

## must_haves

- Schema `updateLoanStatusSchema` aceita `dueDate` opcional (para quando admin aprova e define data de devolução)
- `updateLoanStatus` atualiza `dueDate` quando fornecido no approve
- Frontend mapeia `observation` para `labObservation`
- Endpoint `DELETE /api/notifications/:id` para remover notificação real do banco
- `markAsRead` envia `{ read: true }` no body
- Badge de notificações não lidas na sidebar
- Notificações criadas para todos os cenários (aprovação, rejeição, vencimento)

1. Em `backend/src/controllers/notifications.controller.ts`, adicionar:
```ts
export const deleteNotification = async (req: Request, res: Response) => {
  try {
    const id = getParam(req.params.id);
    if (!id) return res.status(400).json({ success: false, message: 'ID não fornecido' });

    const userId = req.user!.id;

    // Verificar que a notificação pertence ao usuário
    const existing = await prisma.notification.findFirst({
      where: { id, userId },
    });

    if (!existing) {
      return res.status(404).json({ success: false, message: 'Notificação não encontrada' });
    }

    await prisma.notification.delete({ where: { id } });

    return res.json({ success: true, message: 'Notificação excluída' });
  } catch (error) {
    console.error('[deleteNotification]', error);
    return res.status(500).json({ success: false, message: 'Erro interno ao excluir notificação', errors: [String(error)] });
  }
};
```
